# Lucifer

A personal AI assistant for Android that runs the AI model **on the phone itself** — no account, no subscription.

- Chats are saved only on the phone
- Voice input
- Optional web search (DuckDuckGo) with sources
- Private mode: searches go through built-in Tor, with a new IP address every few minutes
- Your own personality instructions

Built on [llama.cpp](https://github.com/ggml-org/llama.cpp) and [tor-android](https://github.com/guardianproject/tor-android).

**Install:** open the latest release on your phone and download the `.apk`.
